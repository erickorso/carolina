# Portal del Despacho

Viceministerio para la Protección Social de la Juventud · Oriana Carolina Vargas Rivas.

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind 4 · Firebase · R3F

## Rutas

- `/` inicio
- `/programas/[slug]`
- `/cursos/[id]`
- `/agenda`
- `/consulta`
- `/despacho`
- `/admin/consultas`

## Arranque

```bash
npm install
cp .env.example .env.local
npm run dev
```

Fotos del banner: `public/banner/` (exportar desde Instagram; el perfil no se puede scrapear).
